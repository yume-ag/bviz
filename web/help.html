bviz cannot run in this browser

The page is not in a secure context

Browsers offer WebGPU only to pages served over HTTPS or from the machine the browser runs on, and this page came over plain HTTP from another machine.

Serve it over HTTPS, or open it as if from this machine by forwarding the server's port, then opening http://localhost:<port>/: 

ssh -L <port>:localhost:<port> <server>

The browser is too old

bviz is WebAssembly that uses fixed-width SIMD and exception handling, which this browser does not run. It needs Chrome 96, Firefox 100, Safari 16.4, or a later version of one of them.

The browser offers no graphics bviz can draw with

bviz draws with WebGPU or, failing that, WebGL2, and this browser offers neither: graphics acceleration may be turned off, or the browser may not trust the graphics driver.

Start Chrome or Chromium on Linux with these flags:

--enable-unsafe-webgpu --ozone-platform=x11 --use-angle=vulkan --enable-features=Vulkan,VulkanFromANGLE

Where it does not trust the graphics driver, add --ignore-gpu-blocklist as well.

Turn on Use graphics acceleration when available in the browser's system settings, and check on chrome://gpu that WebGPU or WebGL2 is hardware accelerated.

Where Firefox on Linux offers no WebGPU, set both dom.webgpu.enabled and gfx.webgpu.ignore-blocklist to true on about:config.

Check that webgl.disabled is false on about:config, and what the graphics section of about:support says of WebGPU and WebGL2.

Check that neither WebGL nor WebGPU is turned off among Safari's feature flags.

Update the browser and the graphics driver, and turn on hardware acceleration in the browser's settings.
